# 南京理工大学《程序设计基础（II）》MIPS 汇编期末复习资料

2019、2020、2023 级期末真题逐题解析，2025 卷大题与 24 级模拟卷全解析，加上算法模板、宏指令展开整理与考前速记。全部内容手工整理，代码在 MARS 4.5（无延迟模型）下验证。

> **关于课件和真题原件**：课件、真题 PDF 与照片涉及版权，本仓库不提供，只在本地使用。需要看原卷时，直接对照 [01-真题解析.md](01-真题解析.md) 与 [02-2025与模拟卷解析.md](02-2025与模拟卷解析.md)——题目、答案、考点都已按原卷顺序整理，不依赖扫描件。
>
> **复习重点的建议**：
>
> - **稳过线**：着重复习真题。近几年试卷改动不大，题型、分值、考点高度重合，把 [01-真题解析.md](01-真题解析.md)、[02-2025与模拟卷解析.md](02-2025与模拟卷解析.md) 与 [03-考前必背.md](03-考前必背.md) 吃透即可。
> - **冲高分**：在真题之外，再研究课件和教材上的例题（如例 5-4～5-7、例 8-1～8-4），真题的翻译题、编程题基本都能在教材例题里找到原型。

## 使用路线

**考前一周**：03 通读 → 01 三套真题各做一遍 → 02 模拟卷限时 120 分钟 → 04 练排序/查找/字符串/递归。

**考前三天**：03 每天三遍；05 的 10 条必背展开默写；02 的错题按考点回看 03、06 对应章节。

**考前一天**：03 + 05 自测 + 默写冒泡、strcmp、Search、Fibonacci 四个模板。

## 口径与声明

- 答案按教材《程序设计基础（II）教程》与课程评卷口径整理；宏展开的临时寄存器一律用汇编器保留的 `$at`（教材 P11）。
- 01、02、04 中的程序逐段汇编运行核对过输出；部分答案为完整程序，部分为函数或代码片段，片段需自补调用入口。
- 2025 卷目前只有照片，只拍到翻译/编程大题与填空题尾部；它与 24 级模拟卷的 40 分大题逐字相同，故 02 以模拟卷结构呈现，并标注 2025 同题。
- 期末真题版权归南京理工大学所有，教材/课件版权归原作者，本仓库仅作学习交流，答案非官方，仅供参考，侵权即删。
- 勘误、补充（尤其 2025 卷完整的选择题与填空题）欢迎提 Issue / PR。

## 运行环境

MARS 4.5，无延迟分支模型。系统调用：`1` 打印整数、`4` 打印字符串、`5` 读整数、`8` 读字符串、`10` 退出、`11` 打印字符、`12` 读字符。
