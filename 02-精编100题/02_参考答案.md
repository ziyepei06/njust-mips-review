# MIPS 期末真题精编 100 题：参考答案

对应 [题目](01_题目.md)。代码按 MARS 4.5 无延迟模型；函数片段只实现题设接口，不能一律当作含 main 的完整程序直接运行。完整程序模板可参考 [06-汇编基础算法示例.md](../06-汇编基础算法示例.md)。

## 一、架构、寄存器与指令格式

### 1. 处理器属性

32 位，RISC；普通整数指令定长 32 位，即 4 字节。「32 位」涉及寄存器、数据通路等宽度，不代表只能访问 32 个内存单元。按字节编址时，32 位地址理论上可表示 2^32 个字节地址，实际可用范围由系统决定。

### 2. 寄存器用途

| 寄存器 | 用途 |
|---|---|
| `$zero` | 恒为 0，写入被丢弃 |
| `$v0/$v1` | 函数返回值；模拟器另以 `$v0` 指定服务号 |
| `$a0..$a3` | 前四个寄存器参数 |
| `$sp` | 当前栈顶 |
| `$fp` | 可选的稳定栈帧基准 |
| `$ra` | 链接返回地址 |

### 3. 寄存器编号

依次是 **4、2、8、9、16、29、30、31**。助记名不直接写入机器码，字段中写的是 5 位编号；寄存器名相似不表示编号相邻。

### 4. 保存责任

①错，`$t` 为调用者保存；调用后仍需用的值由调用者预先保存。②错，若函数改写 `$s0`，返回前应恢复调用前值。③对，不调用子函数且未改写 `$ra`，可直接 `jr $ra`。

### 5. 三类格式

- R：`addu,srl,jr`。字段 `op(6),rs(5),rt(5),rd(5),shamt(5),funct(6)`。
- I：`addi,lw,sw,beq`。字段 `op(6),rs(5),rt(5),imm(16)`。
- J：`j,jal`。字段 `op(6),index(26)`。

### 6. 移位格式

固定移位量使用 R 型的 `shamt` 字段，5 位，范围 0 至 31。是否出现文字常数不能直接决定指令格式。

### 7. 错误指令

`subi` 不是课程基本指令。可写 `addi $t0,$t1,-100`；该形式保留有符号减法可能出现的溢出检测。如果任务明确要求模 2^32 运算，则用 `addiu`。

### 8. 特殊约定

`$at` 是汇编器展开宏时使用的临时寄存器；`$gp` 是全局/静态数据访问基准；`$k0/$k1` 为内核保留，异常处理可能使用，不适合作普通用户程序长期变量。

### 9. 延迟槽

叫分支延迟槽。经典单延迟槽模型中，通常的非 likely 分支，其延迟槽指令无论分支是否成立都会执行。`jal` 链接地址分别是 **P+8** 和本题集的 **P+4**。本题集后续代码不要开启延迟模式。

## 二、数制、位运算与进制转换

### 10. 补码

`$t0=0x00000064`，`$t1=0xFFFFFFFE`。32 位有符号范围为 -2147483648 至 2147483647。

### 11. 补码加法

`11101000=-24`，`11101101=-19`，和为 -43，8 位结果 **11010101**，无溢出。`01111111+00000001=10000000`，两个正数得到负数，有符号溢出；数学和 128 超过 8 位有符号上限 127。

### 12. 扩展规则

依次为 `0xFFFFFFFF`、`0x00000000`、`0x0000FFFF`。`addi` 的 16 位立即数符号扩展；`andi/ori` 的立即数零扩展。`addiu` 中的 u 也不表示立即数零扩展。

### 13. 强制为奇数

**B**。最低位设 1，其余不动。加 1 和异或 1 都会翻转奇偶；与 1 会丢失高位且仍可能得到 0。

### 14. 低 4 位翻转

`xori $t0,$t0,0x000F`；结果 **0x1234567A**。异或 1 翻转，异或 0 保留。

### 15. 指定位翻转

`xori $s0,$s0,0x8080`。掩码是 `(1<<7)|(1<<15)`。`ori` 只能置 1，不能把原来的 1 翻成 0。

### 16. 掩码

```asm
# 三项独立执行
andi $t1,$t0,1
andi $t1,$t0,15
# 第三项
li   $t2,0xFFFFFFF0
and  $t1,$t0,$t2
```

不能用 `andi ...,0xFFF0` 保留高 16 位；立即数零扩展会把高 16 位清零。

### 17. 循环移位

循环左移为 **0x04040404**；普通左移为 **0x04040400**。循环移位把移出的最高 3 位回填到最低 3 位，普通左移丢弃高位并在低位补 0。

### 18. 两种右移

`srl` 得 `0x7FFFFFFC`；`sra` 得 `0xFFFFFFFC`，即 -4。无符号除以 2 用 `srl`。

### 19. 负奇数除以 2

-3 算术右移得到 -2，C 的向零截断得到 -1。负数先加 1 再算术右移可统一修正；正数加 0。

```asm
srl  $t0,$a0,31       # 负数为 1，非负为 0
addu $t0,$a0,$t0
sra  $v0,$t0,1
```

对负偶数加 1 不改变最后向下取整的商，例如 -4 加 1 后右移仍为 -2。

### 20. HI/LO

`mult` 的 64 位乘积高 32 位在 HI，低 32 位在 LO；`div` 的商在 LO，余数在 HI。

```asm
li   $t0,123
li   $t1,100
mult $t0,$t1
mflo $t2             # 12300
li   $t0,-7
li   $t1,2
div  $t0,$t1
mflo $t2             # -3
mfhi $t3             # -1
```

### 21. 统计 0

```asm
CountZero:
    move  $t0,$a0
    li    $t1,32
    move  $v0,$zero
cz_loop:
    andi  $t2,$t0,1
    xori  $t2,$t2,1
    addu  $v0,$v0,$t2
    srl   $t0,$t0,1
    addiu $t1,$t1,-1
    bgtz  $t1,cz_loop
    jr    $ra
```

三组结果分别为 **32、0、31**。必须循环 32 次；按「数变成 0 就结束」只能数有效位，不能统计完整位模式中的前导 0。

### 22. ASCII 二进制

`A` 的 ASCII 是 65，输出 **01000001**。

```asm
.text
.globl main
main:
    li    $v0,12
    syscall
    move  $t0,$v0
    li    $t1,7
ascii_loop:
    srlv  $t2,$t0,$t1
    andi  $t2,$t2,1
    addiu $a0,$t2,48
    li    $v0,11
    syscall
    addiu $t1,$t1,-1
    bgez  $t1,ascii_loop
    li    $v0,10
    syscall
```

### 23. Bin2Hex

```asm
Bin2Hex:
    li    $t0,48
    sb    $t0,0($a1)
    li    $t0,120
    sb    $t0,1($a1)
    sb    $zero,10($a1)
    addiu $t3,$a1,9
    move  $t0,$a0
    li    $t2,8
bh_loop:
    andi  $t1,$t0,15
    blt   $t1,10,bh_digit
    addiu $t1,$t1,87
    b     bh_store
bh_digit:
    addiu $t1,$t1,48
bh_store:
    sb    $t1,0($t3)
    addiu $t3,$t3,-1
    srl   $t0,$t0,4
    addiu $t2,$t2,-1
    bgtz  $t2,bh_loop
    jr    $ra
```

结果分别是 `0x00000000`、`0x80000000`。先放前缀和终止符，再把低位数字依次向前写；对无符号拆位用逻辑右移。函数只写调用者提供的目标区，无共享内部缓冲区。

### 24. 求和位宽

最大结果 `65535*65536/2=2147450880`，能放入有符号 32 位。未除 2 的最大乘积为 4294901760，超出有符号上限。N 偶时算 `(N/2)*(N+1)`，N 奇时算 `N*((N+1)/2)`；每次减半的因子都是偶数。

## 三、宏指令展开

### 25. move 与 not

```asm
addu $t0,$t1,$zero
nor  $t0,$t1,$zero
```

前者复制，后者逐位取反。`addu` 不触发有符号溢出异常。

### 26. ble

```asm
slt $at,$t0,$t1       # t0<t1 时置 1
beq $at,$zero,L      # 其否定，即 t1<=t0
```

用 `slt $at,$t1,$t0` 再与 0 比较会形成另一种条件，不包含正确的大小关系。

### 27. sgti

```asm
addiu $at,$zero,100
slt   $t0,$at,$t1
```

对固定常数 100，也可 `slti $t0,$t1,101` 后 `xori $t0,$t0,1`。这里先得到「小于等于 100」的 0/1，再翻转。不能任意把 `imm+1` 用于超过立即数表示范围的边界。

### 28. 立即数乘法

```asm
addiu $at,$zero,100
mult  $t2,$at
mflo  $t1
```

`mult` 没有第三个立即数操作数。这里保证结果范围，因此低 32 位就是所需完整结果。

### 29. rol 展开

```asm
sll $t1,$t0,3
srl $t2,$t0,29
or  $t0,$t1,$t2
```

两个移位都必须以原始 `$t0` 为源；过早覆盖输入会丢失待回填的高位。

## 四、寻址、访存与数据对齐

### 30. 基址寻址

有效地址 **0x10010004**；基址 `$a0`，有符号偏移 -4，基址寻址。`la` 取得地址，`lw` 从该地址读取 32 位数据；`la` 常需展开为多条指令。

### 31. word 数组

21 是下标 **8**，地址 `0x10010004+8*4=0x10010024`。

### 32. half 数组

八月下标 8，地址 `0x10010008+8*2=0x10010018`。`.half` 一个元素 2 字节，不是 4 字节。

### 33. 小端加载

| 操作 | 结果 |
|---|---|
| 整字 `lw` | `0x92345678` |
| `lb +3` | `0xFFFFFF92` |
| `lbu +3` | `0x00000092` |
| `lh +2` | `0xFFFF9234` |
| `lhu +2` | `0x00009234` |

`lb/lh` 符号扩展，`lbu/lhu` 零扩展。

### 34. sb 覆盖

从低地址到高地址为 **FF 00 FF 00**，整字值 **0x00FF00FF**。`sb` 只写寄存器低 8 位，不是把整个寄存器写入。

### 35. 重组后写入

读出字节 FF、7F，合并为 `0x00007FFF`。写入 x 开始的四字节后为 **FF 7F 00 00**，所以 **x=32767，y=0**。x 只声明了 2 字节，但 `sw` 会写 4 字节；本题地址对齐，因此问题是覆盖相邻对象，不是必然非对齐异常。

### 36. 对齐

`.ascii` 字符串长度 7，补 1 字节，num=`0x10010008`。改为 `.asciiz` 后共占 8 字节，补 0 字节，num 地址相同。

### 37. 对齐指示语句

`.align 2`，按本课程 SPIM/MARS 指示语义对齐到 `2^2=4` 字节，最多补 3 字节。本题 num 占 1 字节，需补 3 字节。不要误解为对齐到 2 字节。

### 38. 步长

分别加 **1、2、4**。字数组地址：

```asm
sll  $t1,$t0,2
addu $t1,$a0,$t1
```

### 39. 半字插入

第一次移位写入 `0x10010006`，低地址字节 **2C**，高地址字节 **01**。随后 `$a0` 减 2，加载 100，满足 100<=200，故到达 insert 时 `$t1=100`。最后四个半字是 **-1、100、200、300**。

### 40. 存储执行

| 阶段 | 内容 |
|---|---|
| IF | 从 `0x00400010` 取指到 IR，顺序 PC 增至 `0x00400014` |
| RD | 读 `$a0=0x10010004`、`$t1=0x0000012C`，把立即数 2 符号扩展 |
| ALU | 加出有效地址 `0x10010006` |
| MEM | 在该地址写 2C，下一字节写 01 |

存储指令不向通用寄存器回写；若画统一五阶段图，WB 标「无寄存器写入」。

## 五、机器码、分支地址与链接

### 41. bne 编码

bne 位于 `P=0x00400008`，目标 T=`0x00400000`，偏移 `(T-(P+4))/4=-3`，16 位为 FFFD。

```text
op     rs     rt     imm
000101 01000  00000  1111111111111101
```

结果 **0x1500FFFD**。

### 42. sh 编码

```text
op     rs     rt     imm
101001 00100  01001  0000000000000010
```

`rs=$a0=4` 为基址，`rt=$t1=9` 为待存数据；结果 **0xA4890002**。

### 43. 宏与地址

地址依次为：addiu=`0x00400000`，lh=`...04`，slt=`...08`，beq=`...0C`，sh=`...10`，addiu=`...14`，bgez=`...18`，insert 的 sh=`...1C`。beq 偏移 `(0x1C-0x10)/4=3`。省略号沿用同一 `0x004000` 前缀。

### 44. 两条路径

偏移 `(0x00400010-0x00400020)/4=-4`，字段 **0xFFFC**。成立时下一地址 `0x00400010`，不成立 `0x00400020`。本题关闭延迟槽。

### 45. 条件链接

`$t0>=0` 时转移；发生链接时 `$ra=0x0001234C`。偏移 `(0x12400-0x1234C)/4=45=0x002D`。经典单延迟槽模型的链接地址会不同，不混入本题。

### 46. 反汇编

①`sh $t1,2($a0)`。②字段 `op=0,rs=9,rt=10,rd=8,shamt=0,funct=0x21`，结果 **0x012A4021**。第①项交换 rs/rt 会把数据寄存器错当基址。

## 六、异常与 CP0

### 47. 算术异常

①对，例如 `$a0=0x40000000`，倍增超出有符号上限。②错，同一个值减自己恒为 0。③错，`mult` 设计为在 HI/LO 中保存 64 位结果，不能以超过 32 位直接判作 add 式溢出。④错，真实基本除法与模拟器/伪指令对除零的处理必须区分，不能跨所有模型断言同一种异常。遇到原卷单选的歧义，应写明课程/模拟器约定。

### 48. CP0 寄存器

| 编号 | 名称 | 内容 |
|---|---|---|
| 8 | BadVAddr | 地址异常相关的错误虚拟地址 |
| 12 | Status | 执行状态、中断使能/屏蔽等 |
| 13 | Cause | 异常原因及相关标志，ExcCode 在位 6 至 2 |
| 14 | EPC | 异常返回参考地址；无延迟槽异常时通常记录出错指令地址 |

EPC 是代码地址，BadVAddr 是错误访问的数据或取指地址，Cause 编码异常类型。非地址异常时不能把 BadVAddr 的旧值当成新错误地址。

### 49. 非对齐访问

num=`0x10010007`，`sw $t0,4($a0)` 的地址为 **0x1001000B**，未按字对齐，故该 sw 出错。BadVAddr=`0x1001000B`；本题 EPC=`0x00400004`。题设显式关闭自动对齐，不能再假定汇编器替你补齐。

### 50. 异常码

ExcCode=**5**，即存储地址错误；BD=1，表示异常发生在分支延迟槽中。BD 的解码是独立给定现场的分析，不表示本题集程序已开启延迟槽。

```asm
mfc0 $k0,$13
srl  $a0,$k0,2
andi $a0,$a0,0x1F
```

只右移会把高位 BD/IP 等也带入，必须保留目标 5 位。

### 51. 硬件动作

硬件记录 EPC、Cause，地址异常时记录 BadVAddr；按模型更新 Status，进入异常处理状态并限制中断；最后把控制流转向异常入口，从那里取指，开始执行异常处理程序。不同模型可有不同入口与状态位规则，本题不要求强加一个通用先后顺序。硬件不会自动把全部通用寄存器压到软件栈；处理程序自己保存所需现场。

### 52. 修复及显示

数据定义中插入 `.align 2`。已进入异常处理例程时，读取、提取和打印片段可写：

```asm
mfc0 $k0,$13
srl  $a0,$k0,2
andi $a0,$a0,0x1F
li   $v0,1
syscall
```

内核中能否直接使用模拟器 syscall 服务取决于运行环境；此处只考接口片段，不作为跨模拟器内核例程。原题若只写 `andi ...,0x7C`，得到的是移位前的字段掩码值，还需右移 2 位才是十进制异常码。

## 七、控制结构翻译与数值算法

### 53. 比较分支

允许伪指令：`bge $t0,$t1,CHANGE`、`blt $t0,$t1,CHANGE`。基本形式分别为：

```asm
# t0>=t1
slt $at,$t0,$t1
beq $at,$zero,CHANGE
# t0<t1
slt $at,$t0,$t1
bne $at,$zero,CHANGE
```

### 54. 常数比较

`slti $t0,$t1,100` 得到小于条件。大于可用第 27 题的常数装载加反向 `slt`。`slt` 的两个源操作数必须是寄存器，不能把 100 作为第二个源寄存器。

### 55. 绝对值

```asm
bgez $t0,abs_nonneg
subu $t7,$zero,$t0
b    abs_done
abs_nonneg:
move $t7,$t0
abs_done:
```

INT_MIN 的数学绝对值是 2147483648，超出有符号 32 位；换成不报溢出的 `subu` 不能使其变成可表示的正整数。

### 56. if/else

```asm
bgt  $t0,$t1,pick_y
move $t2,$t0
b    pick_done
pick_y:
move $t2,$t1
pick_done:
```

真分支必须跳过假分支。

### 57. 哨兵循环

```asm
sent_loop:
beqz  $t0,sent_done
addu  $s1,$s1,$t0
addiu $t2,$t2,4
lw    $t0,0($t2)
b     sent_loop
sent_done:
```

该片段是题设寄存器翻译，不是独立函数；若嵌入普通函数并改写 `$s1`，要履行保存责任。

### 58. 循环求和

```asm
# a0=N，t0=i，v0=sum
li    $t0,1
move  $v0,$zero
sum_for:
bgt   $t0,$a0,sum_for_ret
addu  $v0,$v0,$t0
addiu $t0,$t0,1
b     sum_for
sum_for_ret:
jr    $ra
```

先判断再累加，所以 N=0 返回 0。

### 59. 循环翻译

```c
int sum = 0;
if (N > 0) {
    int x = N;
    do { sum += x; --x; } while (x > 0);
}
/* 输出 sum */
```

输出依次为 **0、0、10**。删除前测后，N<=0 仍会执行一次累加；负数将产生错误结果。

### 60. 表达式翻译

```asm
sll   $t0,$s1,2
addu  $t0,$s2,$t0
lw    $t1,0($t0)       # C[b]
srl   $t2,$s0,2        # 题设 a>=0
addiu $t2,$t2,45
sll   $t2,$t2,5
subu  $s0,$t1,$t2
```

非负 a 下逻辑右移可做除以 4；若放宽到负数，需处理向零舍入。

### 61. SUM

```asm
SUM:
    li    $v0,-1
    bltz  $a0,sum_ret
    li    $t0,65535
    bgt   $a0,$t0,sum_ret
    move  $t1,$a0
    addiu $t2,$a0,1
    andi  $t0,$a0,1
    beqz  $t0,sum_even
    srl   $t2,$t2,1
    b     sum_mul
sum_even:
    srl   $t1,$t1,1
sum_mul:
    mult  $t1,$t2
    mflo  $v0
sum_ret:
    jr    $ra
```

负数与大于 65535 的输入直接返回 -1。合法分支的两个因子乘积已处于有符号范围。

### 62. 奇偶路径

```asm
andi  $t0,$a0,1
beqz  $t0,halve_n
srl   $t1,$t1,1
b     factors_done
halve_n:
srl   $a0,$a0,1
factors_done:
```

若用 `$a0` 和 `$t1` 作因子，N=4 得 **2、5**；N=5 得 **5、3**。奇数分支末尾的跳转防止再次减半 N。

### 64. Fibonacci 式迭代

```asm
Fib:
    li    $t0,1
    move  $t1,$zero
    move  $t2,$a0
```

先计算新值，再依次更新 a、b。N=0 返回 0；本函数的题设输入限制保证结果不溢出。

### 65. 每轮状态

| 轮次 | a | b | c |
|---|---:|---:|---:|
| 1 | 0 | 1 | 1 |
| 2 | 1 | 1 | 1 |
| 3 | 1 | 2 | 2 |
| 4 | 2 | 3 | 3 |
| 5 | 3 | 5 | 5 |

N=0 返回 0。如果先赋 `a=b`，旧 a 消失，后续的 `a+b` 变成旧 b 的两倍，递推关系改变。

### 66. 服务号

| 号 | 服务 | 关键输入 | 返回 |
|---|---|---|---|
| 1 | 打印整数 | `$a0` 整数 | 无所需返回值 |

### 67. 最大边界

判断错误。N=65535 时结果 **2147450880**，正确减半因子后无需拒绝。N 非负是公式函数的输入约定，也保证逻辑右移减半的语义。`mult` 保留 64 位结果；单取 LO 会丢弃 HI，只有已证明结果范围或明确要求模 2^32 运算时才能如此使用。

### 68. strcmp 的 C 翻译

```c
int strcmp_m(const unsigned char *s, const unsigned char *t) {
    for (;;) {
        unsigned char x = *s++;
        unsigned char y = *t++;

```

接口：两个零结尾字节串的地址；返回首个不同字节之差，或共同结束时的 0。结果符号表示比较关系，不保证仅取 -1/0/1。

### 70. CopyN


先检查复制数量，再读源；n=0 时直接写目标零字节，不读源。只在有效复制后推进计数。

### 71. 原题风格 Copy

```c
int copy_exam(const char *src, char *dst, int n) {
    int copied = 0;
    do {
        char ch = *src++;
        *dst++ = ch;
        if (ch == 0) return copied;
        ++copied;
    } while (copied < n);
    *dst = 0;
    return copied;
}
```

源为空串：先复制零字节，返回 0。n=0 且源非空：仍复制首字符，再写零，返回 1；因此不能满足第 70 题的零长度约定，且需要至少 2 字节目标区。n=3 时至多复制前三个非零字符并终止，遇源零提前返回；不把源串终止零计入返回数，也不填满后续目标区。

### 75. 字符串边界

①结束标记为数值 0，`'0'` 为 ASCII 48。②检查换行和零字节任一；缓冲区满时未必读到换行。③服务容量不能超过实际缓冲区，128 字节传 128，通常最多存 127 个字符加终止零。④从 `base+len-1` 开始，并先处理 len=0；不要把零字节当作可见字符输出。

### 78. Search

### 80. BubbleSort

```asm
BubbleSort:
    addiu $t0,$a1,-1
bs_outer:
    blez  $t0,bs_ret
    move  $t1,$a0
    move  $t2,$zero
bs_inner:
    lw    $t3,0($t1)
    lw    $t4,4($t1)
    ble   $t3,$t4,bs_next
    sw    $t4,0($t1)
    sw    $t3,4($t1)
bs_next:
    addiu $t1,$t1,4
    addiu $t2,$t2,1
    blt   $t2,$t0,bs_inner
    addiu $t0,$t0,-1
    b     bs_outer
bs_ret:
    jr    $ra
```

外层把本轮最后比较位置从 N-1 逐步缩至 1；内层比较相邻两项，较大值后移。内层本轮比较次数为该外层值。N<=1 时先返回，不加载第二项。

### 81. 栈数组完整程序

```asm
.text
.globl main

    addiu $sp,$sp,-16
    sw    $s0,0($sp)
    sw    $s1,4($sp)
    sw    $s2,8($sp)
    sw    $ra,12($sp)
    li    $v0,5

    move  $s1,$v0

    sll   $s2,$s1,2

    move  $s0,$sp
    move  $t0,$zero
input_loop:
    li    $v0,5
    syscall
    sll   $t1,$t0,2
    addu  $t1,$s0,$t1
    sw    $v0,0($t1)
    addiu $t0,$t0,1
    blt   $t0,$s1,input_loop
    move  $a0,$s0
    move  $a1,$s1
    jal   BubbleSort
    move  $t0,$zero

    sll   $t1,$t0,2
    addu  $t1,$s0,$t1
    lw    $a0,0($t1)
    li    $v0,1
    syscall
    li    $a0,10
    li    $v0,11
    syscall
    addiu $t0,$t0,1
    blt   $t0,$s1,output_loop
    addu  $sp,$sp,$s2
main_restore:
    lw    $s0,0($sp)
    lw    $s1,4($sp)
    lw    $s2,8($sp)
    lw    $ra,12($sp)
    addiu $sp,$sp,16
    li    $v0,10
    syscall
BubbleSort:
    addiu $t0,$a1,-1
bs_outer:
    blez  $t0,bs_ret
    move  $t1,$a0
    move  $t2,$zero
bs_inner:
    lw    $t3,0($t1)
    lw    $t4,4($t1)
    ble   $t3,$t4,bs_next

bs_next:

```

N、数组首地址、数组字节数分别放 `$s1/$s0/$s2`，排序函数遵守 `$s` 保存约定。排序前的 `$t0` 不用于跨调用保留，返回后重新清零。程序使用课程式按字分配布局，不声称遵循所有平台完整 ABI 的栈对齐要求。

### 82. 插入算法

```c
int j = 2;
while (a[j] > 200) {
    a[j+1] = a[j];
    --j;
}
a[j+1] = 200;
```

题设首元素 -1 充当小于目标值的哨兵，所以本例不会越过头部；泛化到任意数组时需增加 `j>=0`。本例结果 **-1、100、200、300**。循环不变量：当前空位右侧已移出的元素都大于目标值，且保持原相对顺序；空位随比较向左移动。插入以移动腾位为主，冒泡通过相邻交换逐轮把极值送到端部。

### 83. 去重算法

```c
int getSet(int rs[], const int a[], int n) {
    int j = 0;
    for (int i = 0; i < n; ++i) {
        int k;
        for (k = 0; k < j; ++k)
            if (a[i] == rs[k]) break;
        if (k == j) rs[j++] = a[i];
    }
    return j;
}
```

输出有效前缀 **2、1、3**，返回 **3**。j=0 时不读 rs 的未初始化元素；n=0 返回 0。

### 84. 函数接口

| 函数 | 地址参数 | 数值参数 | 结果 |
|---|---|---|---|
| Search | `$a0` 数组地址 | `$a1=N,$a2=V` | `$v0` 下标或 -1 |

### 85. 跨调用保护

BubbleSort 可以改写 `$t0`，调用者不能依赖其原值。栈方案在调用前分配独立槽保存，调用后读回：

```asm
addiu $sp,$sp,-8
sw    $t0,0($sp)
jal   BubbleSort
lw    $t0,0($sp)
addiu $sp,$sp,8
```

该片段所在的非叶调用者还应在自己的外层帧保存 `$ra`。`$s0` 方案：在调用者入口保存旧 `$s0`，用 `$s0` 放 N，退出前恢复；不能因为使用保存寄存器就省去自己对上级调用者的责任。

### 86. 非叶函数

```asm
F:
    addiu $sp,$sp,-8
    sw    $ra,4($sp)
    jal   G
    addiu $v0,$v0,1
    lw    $ra,4($sp)
    addiu $sp,$sp,8
    jr    $ra
```

不保存会使 `$ra` 保持 F 内 `jal G` 后一条指令的地址，`jr $ra` 回到自己的后半段，可能反复执行并破坏栈。

|---|---|
| 保存 `$s0` | S-16 |
| 保存 `$s1` | S-12 |
| 局部变量 | S-8 |
| 保存 `$ra` | S-4 |

### 88. 栈接口

### 89. getSet 的栈实现

```asm
GetSetStack:
    lw    $t7,0($sp)       # rs
    lw    $t8,4($sp)       # a
    lw    $t9,8($sp)       # n
    move  $t0,$zero        # i
    move  $t1,$zero        # j，已收集的个数
set_outer:
    bge   $t0,$t9,set_ret
    sll   $t2,$t0,2
    addu  $t2,$t8,$t2
    lw    $t3,0($t2)       # 当前 a[i]
    move  $t4,$zero        # k
set_inner:
    bge   $t4,$t1,set_add
    sll   $t5,$t4,2
    addu  $t5,$t7,$t5
    lw    $t6,0($t5)
    beq   $t3,$t6,set_next
    addiu $t4,$t4,1
    b     set_inner
set_add:
    sll   $t5,$t1,2
    addu  $t5,$t7,$t5
    sw    $t3,0($t5)
    addiu $t1,$t1,1
set_next:
    addiu $t0,$t0,1
    b     set_outer
set_ret:
    sw    $t1,12($sp)
    jr    $ra
```

入口即读出三个参数；不移动 `$sp`，所以返回槽始终为 12 偏移。叶函数不执行 jal，不必另存 `$ra`。源与结果区要求不重叠；n=0 时不访问数组。

### 90. f1 结果

最终 **`$v0=10,$v1=3,$a0=4`**。入口参数依次 4、3、2、1；最内层减为 0 后停止递归。回退依次恢复并加入 **1、2、3、4**。`$v1` 只在继续递归前自增，故为 3。

### 91. 次数公式

入口 n>=1 时：进入次数 n，递归 `jal f1` 执行 n-1 次，`$v1` 增量 n-1，返回和 `n(n+1)/2`。若调用前 `$v0/$v1` 非零，最终是在原值上累加，不能忽略前置清零。

- n=50：和 1275，进入 50 次，递归链接 49 次，计数增量 49。
- n=100：和 5050，进入 100 次，递归链接 99 次，计数增量 99。

### 92. 递归栈

| 入口参数 | 入口 sp | 参数保存位置 | `$ra` 保存位置 | 分配后 sp |
|---|---|---|---|---|
| 3 | S | S | S-4 | S-24 |
| 2 | S-24 | S-24 | S-28 | S-48 |
| 1 | S-48 | S-48 | S-52 | S-72 |

最深 `$sp=S-72`。每层参数保存在入口 sp，属于已约定的入参槽；外层调用者提供首个槽，各层分配的新空间又为下一层提供入口槽。一般函数若没有这种接口保证，必须先分配自己的空间再存现场。

### 93. 普通递归求和

```asm
RecSum:
    beqz  $a0,rs_zero
    addiu $sp,$sp,-8
    sw    $a0,0($sp)
    sw    $ra,4($sp)
    addiu $a0,$a0,-1
    jal   RecSum
    lw    $t0,0($sp)
    addu  $v0,$v0,$t0
    lw    $ra,4($sp)
    addiu $sp,$sp,8
    jr    $ra

    jr    $ra
```

非零层在 0 偏移保存 n，4 偏移保存 `$ra`；递归返回后先取回 n，再加到结果。n=0 的叶层不分配帧，不把已经被下层调用改写的临时寄存器当成原 n。

### 94. 可重入判断

①错，还要避免共享可变工作区并正确处理各次调用现场。②错，全局可变缓冲区会被不同调用覆盖。③对，前提是各调用栈空间独立且生存期足够。④对，只读常量可共享。⑤错，跨递归调用仍要使用的参数、局部状态和返回地址必须按约定保留。

### 95. 栈缓冲区与生存期

```asm
ReadLine:
    addiu $sp,$sp,-136
    sw    $s0,128($sp)
    sw    $ra,132($sp)
    move  $s0,$sp
    move  $a0,$s0
    li    $a1,128
    li    $v0,8
    syscall
    move  $a0,$s0
    jal   Consume
    lw    $s0,128($sp)
    lw    $ra,132($sp)
    addiu $sp,$sp,136
    jr    $ra
```

释放后不能返回该局部区作持久结果；后续调用可重用同一栈地址。应在帧有效期间消费，或写到调用者提供且生存期足够的缓冲区。题设使用固定容量 128，此处直接装载该容量。

### 96. 偏移与 fp

新 sp=入口 sp-16，原参数应访问 **16($sp)**。若 `$fp` 固定为入口 sp，则用 **0($fp)**。动态改变 sp 后，稳定基准仍能定位参数；使用 `$fp` 的函数必须保存并恢复调用者的旧 fp。

### 97. 固定帧与动态数组

令入口栈顶 S、数组分配后栈顶 B=`S-16-4N`：

```text
高地址
S                  入口栈顶
S-4                保存 ra
S-8                保存 s2（数组字节数）
S-12               保存 s1（N）
S-16               保存 s0；固定帧起点
B .. S-17          N 个 int 的数组区
B                  最终 sp、数组首地址
低地址
```

动态区存在时，保存的 s0 在 `B+4N`，ra 在 `B+4N+12`。先令 sp+=4N 回到固定帧起点，再按 0/4/8/12 恢复，最后 sp+=16。反过来按固定偏移恢复会把数组元素当成寄存器现场。

### 98. 两个返回值跨服务保留

```asm
ShowExtrema:
    addiu $sp,$sp,-16
    sw    $ra,12($sp)
    jal   MinMax
    sw    $v0,0($sp)
    sw    $v1,4($sp)
    lw    $a0,0($sp)
    li    $v0,1
    syscall
    li    $a0,10
    li    $v0,11
    syscall
    lw    $a0,4($sp)
    li    $v0,1
    syscall
    lw    $ra,12($sp)
    addiu $sp,$sp,16
    jr    $ra
```

`$v0` 同时承担返回值与系统服务号角色，一设置服务号原值就被覆盖；预先写栈使两个结果都独立保存。

### 99. 统一出口

错误分支未释放帧，sp 会持续偏移，后续调用可能错误读取现场或逐步耗尽栈。若函数调用子函数，直接使用被改写的 ra 还会返回到错误位置。结构应为：

```asm
# 入口已分配帧并将 ra 保存于 12(sp)
# 正常路径...
b func_exit
func_error:
li $v0,-1
func_exit:
lw    $ra,12($sp)
# 这里还应恢复本函数使用的其他保存寄存器
addiu $sp,$sp,16
jr    $ra
```

### 100. 综合检查

错误一：先释放帧再以旧偏移读取 ra，地址已经变了。错误二：没有恢复 `$s0`。

```asm
lw    $s0,0($sp)
lw    $ra,12($sp)
addiu $sp,$sp,16
jr    $ra
```

四项检查：**参数/返回槽是否符合题设；跨调用活跃值是否保留；保存寄存器及 ra 是否正确恢复；每条返回路径的栈增减是否配对。**
