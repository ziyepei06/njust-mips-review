程序设计基础（II）。满分 100 分，时间 120 分钟。

约定：32 位，小端，延迟槽关闭。系统调用号按 MARS：1 打印整数，4 打印字符串，5 读整数，8 读字符串，10 退出，11 打印字符。

本卷是按 2019、2020 的题型新编的练习卷，不是学校原题。

## 三、程序翻译（共 20 分）

```asm

a: .word -2,0,5,-7,8,1
.text
main:
    la    $a0,a
    li    $t0,6
    move  $v0,$zero
lp: beqz  $t0,out
    lw    $t1,0($a0)
    blez  $t1,nx
    addiu $v0,$v0,1
nx: addiu $a0,$a0,4
    addiu $t0,$t0,-1
    b     lp
out:
```

     beqz  $t0,R
     addiu $v0,$v0,1
     addiu $a0,$a0,1
     b     L
R:   jr    $ra

3. （10 分）把函数译成 MIPS。`$a0` 为数组首地址，`$a1` 为 n，`$v0` 返回结果。只写函数。

```c
int sumEven(int a[], int n) {
    int s = 0;
    for (int i = 0; i < n; i++)
        if ((a[i] & 1) == 0) s += a[i];
    return s;
}
```
