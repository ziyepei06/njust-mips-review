# 模拟卷参考答案

约定与试卷相同：32 位，小端，延迟槽关闭。机器码和地址已按这个约定核算。能完成同一任务的其他写法同样得分；下面给出一种。

# 模拟卷甲

## 一、选择

1. D。`sll` 是 R 型。前三条是 I 型。
2. B。`$v0`。
3. B。40 是 `0x28`，−16 的 32 位补码是 `0xFFFFFFF0`。
4. A。`0x22334411`。高 8 位移到最低 8 位，其余左移 8 位。C 是不把移出的位补回的结果。
5. A。`andi` 的立即数零扩展，掩码 `0x0F` 留下低 4 位。`0xAB` 得到 `0x0B`。
6. B。`add` 在有符号溢出时产生异常。`addu` 不检测溢出。
7. A。C 的条件是 `$t0 >= $t1`。
8. B。小端存放后，地址最低字节是 `0x44`。`lb` 做符号扩展，`0x44` 的最高位是 0，结果仍是 `0x00000044`。
9. B。`$ra`。
10. A。`bne` 在 `loop` 后 4 字节处。下一条地址相对 `loop` 是 +8，立即数是 `(0-8)/4 = -2`，即 `0xFFFE`。op=5，rs=8，rt=0，机器码 `0x1500FFFE`。

## 二、填空

1. 基址寻址。`lw $t0,8($s0)`。
2. EPC，编号 14。
3. `addu $t0,$t1,$zero`。`add $t0,$t1,$zero` 也对。
4. `0x1001001C`。16 是下标 4，偏移 16 字节。
5. `L` 在 `0x00400014`。`beq` 在 `0x00400018`，`M` 在 `0x00400020`。成立时 PC 为 `0x00400020`，不成立时为 `0x0040001C`。
6. `$t0 < 0`。写入 `$ra`，值为 `0x00400034`。延迟槽关闭，返回地址是本指令的下一条。
7. `slt $at,$t0,$t1`，然后 `beq $at,$zero,L`。`$t0 < $t1` 不成立时转移。
8. `0xFFFF807F`。低字节 `0x7F` 是半字的低 8 位，高字节 `0x80` 使半字为负数，`lh` 符号扩展。
9. `$v0=21`，`jal` 执行 5 次。进入时的参数 6、5、4、3、2、1 在返回时相加。参数减到 0 的那一层不再调用。
10. 第一空 `bge $t2,$v0,next`。第二空 `b loop`。新值大于等于当前最小值时跳过更新。

## 三、翻译

1. 统计数组里大于 0 的个数。结果是 3，来自 5、8、1。0 不计数。

```c
int a[] = {-2,0,5,-7,8,1};
int n = 6, count = 0;
for (int i = 0; i < n; i++)
    if (a[i] > 0) count++;
```

2. `$a0` 是以 0 结尾的字节串，`$v0` 返回结束符之前的字节数。空串返回 0。

```c
int len(const unsigned char *s) {
    int n = 0;
    while (*s != 0) {
        n++;
        s++;
    }
    return n;
}
```

3. 偶数用最低位判断。−2 的最低位也是 0，应当加进和里。

```asm
sumEven:
    move  $v0,$zero
    move  $t0,$zero
se:
    bge   $t0,$a1,se_rt
    sll   $t1,$t0,2
    addu  $t1,$a0,$t1
    lw    $t2,0($t1)
    andi  $t3,$t2,1
    bnez  $t3,se_nx
    addu  $v0,$v0,$t2
se_nx:
    addiu $t0,$t0,1
    b     se
se_rt:
    jr    $ra
```

## 四、编程

1. 固定循环 32 次。输入 0 得 0，输入 7 得 3。

```asm
Ones:
    move  $v0,$zero
    li    $t0,32
oc:
    andi  $t1,$a0,1
    addu  $v0,$v0,$t1
    srl   $a0,$a0,1
    addiu $t0,$t0,-1
    bnez  $t0,oc
    jr    $ra
```

2. 缓冲区在栈上。读指针遇到 0 或换行结束，写指针跳过空格。输入 `a b c` 输出 `abc`。

```asm
.text
.globl main
main:
    addiu $sp,$sp,-128
    move  $a0,$sp
    li    $a1,128
    li    $v0,8
    syscall
    move  $t0,$sp
    move  $t1,$sp
pk:
    lbu   $t2,0($t0)
    beqz  $t2,pk_end
    beq   $t2,10,pk_end
    beq   $t2,32,pk_sk
    sb    $t2,0($t1)
    addiu $t1,$t1,1
pk_sk:
    addiu $t0,$t0,1
    b     pk
pk_end:
    sb    $zero,0($t1)
    move  $a0,$sp
    li    $v0,4
    syscall
    addiu $sp,$sp,128
    li    $v0,10
    syscall
```

# 模拟卷乙

## 一、选择

1. D。`jr` 使用寄存器寻址。
2. B。`$a0`。
3. A。−2 是 `0xFFFFFFFE`，127 是 `0x7F`。
4. B。`0x08000000`。逻辑右移从高位补 0。A 是算术右移的结果。
5. A。掩码 `0x00F0` 对应位 4 到位 7。
6. B。除数为 0 时 `div` 产生异常。
7. B。C 的条件是 `$t0 < $t1`。
8. B。`0x04020304`。小端四个字节原本是 `04 03 02 01`。`sb` 把 `$t1` 的低 8 位 `0x04` 写到偏移 3，最高字节从 `0x01` 变成 `0x04`。
9. A。`$sp`。
10. B。`bne` 前面有两条指令，立即数是 −3，即 `0xFFFD`。rs 仍是 `$t0`，机器码 `0x1500FFFD`。C 把 rs 误当成 `$s1`。

## 二、填空

1. 被调用者。恢复调用前的值。
2. Cause，编号 13。ExcCode 在位 6 到 2。
3. `nor $t0,$t1,$zero`。
4. `0x1001001E`。八月是下标 7，每个半字 2 字节，偏移 14。
5. `out` 在 `0x00400010`。立即数是 2。`beq` 的下一条地址是 `0x00400008`，目标比它远 2 条指令。
6. `0x00400044`。
7. 位型 `10100000`。溢出。两个正数之和是 160，超出 8 位补码的最大正数 127，结果位型的符号位为 1。
8. `0x00000003`。偏移 1 上的字节是 `0x03`，`lbu` 零扩展。
9. `$v0=10`，`jal` 执行 3 次。相加的参数是 4、3、2、1。
10. 第一空 `move $v0,$t2`。第二空 `move $v1,$t2`。

## 三、翻译

1. 把 `'a'` 到 `'z'` 减 32。字符串变成 `GO2`。

```c
char s[] = "Go2";
for (char *p = s; *p != '\0'; ++p)
    if (*p >= 'a' && *p <= 'z') *p -= 32;
```

2. `$a0` 是源地址，`$a1` 是目标地址，`$a2` 是字节数。原样复制这么多个字节，不额外补 0。n 为 0 时一次也不复制。函数没有用 `$v0` 返回结果。

```c
void copy_n(const unsigned char *src, unsigned char *dst, unsigned n) {
    while (n != 0) {
        *dst++ = *src++;
        n--;
    }
}
```

3. 第一段在 `$t0` 为正时复制，否则取相反数。0 走 else，结果仍是 0。`$t0` 为 `0x80000000` 时，相反数超出 32 位有符号范围，`subu` 得到的位型仍是 `0x80000000`。

```asm
blez  $t0,neg
move  $t1,$t0
b     abs_d
neg:
subu  $t1,$zero,$t0
abs_d:
wh:
blez  $t2,wh_d
lw    $t4,0($t3)
addu  $s0,$s0,$t4
addiu $t3,$t3,4
addiu $t2,$t2,-1
b     wh
wh_d:
```

4. `C[3]` 的字节偏移是 12。12 逻辑右移 2 位等于 3。新的 `A` 等于 `C[3] + 3`。

```asm
.data
A: .word 0
C: .word 0,0,0,0,0,0,0,0
.text
li    $t0,12
sw    $t0,A
la    $t1,C
lw    $t2,12($t1)
srl   $t0,$t0,2
addu  $t0,$t2,$t0
sw    $t0,A
```

`C` 若已经由别处赋过值，这里不要再写成全 0。右移可以用已经放在 `$t0` 里的 12，因为此时 `A` 仍是这个非负数。

## 四、编程

1. N 为 0 时不读内存，直接返回 −1。多个相同值返回最前面的下标。

```asm
Search:
    li    $v0,-1
    move  $t0,$zero
se:
    bge   $t0,$a1,se_rt
    sll   $t1,$t0,2
    addu  $t1,$a0,$t1
    lw    $t2,0($t1)
    beq   $t2,$a2,se_fd
    addiu $t0,$t0,1
    b     se
se_fd:
    move  $v0,$t0
se_rt:
    jr    $ra
```

2. 数组占 `4N` 字节，放在保存寄存器的下面。输入 `3` 和 `4 -1 4` 时，先输出 4，再输出 −1。

```asm
.text
.globl main
main:
    addiu $sp,$sp,-16
    sw    $s0,0($sp)
    sw    $s1,4($sp)
    sw    $ra,8($sp)
    li    $v0,5
    syscall
    move  $s1,$v0
    sll   $t0,$s1,2
    subu  $sp,$sp,$t0
    move  $s0,$sp
    move  $t1,$zero
in:
    li    $v0,5
    syscall
    sll   $t2,$t1,2
    addu  $t2,$s0,$t2
    sw    $v0,0($t2)
    addiu $t1,$t1,1
    blt   $t1,$s1,in
    lw    $t3,0($s0)
    move  $t4,$t3
    li    $t1,1
scan:
    beq   $t1,$s1,out
    sll   $t2,$t1,2
    addu  $t2,$s0,$t2
    lw    $t5,0($t2)
    ble   $t5,$t3,ckn
    move  $t3,$t5
ckn:
    bge   $t5,$t4,scn
    move  $t4,$t5
scn:
    addiu $t1,$t1,1
    b     scan
out:
    move  $a0,$t3
    li    $v0,1
    syscall
    li    $a0,10
    li    $v0,11
    syscall
    move  $a0,$t4
    li    $v0,1
    syscall
    li    $a0,10
    li    $v0,11
    syscall
    sll   $t0,$s1,2
    addu  $sp,$sp,$t0
    lw    $s0,0($sp)
    lw    $s1,4($sp)
    lw    $ra,8($sp)
    addiu $sp,$sp,16
    li    $v0,10
    syscall
```
